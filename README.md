# adib-server

بک‌اند ادیب برای اتصال امن به گلستان، تشخیص نمره جدید، و ارسال نوتیفیکیشن تلگرام.

## این پروژه چیکار می‌کنه (و چیکار نمی‌کنه)

- گذرواژه گلستان رو **رمزنگاری‌شده (AES-256-GCM)** روی دیسک نگه می‌داره، نه متن ساده.
- یک اسکلت آماده برای اتوماسیون ورود به گلستان با Puppeteer داره (`src/services/golestanScraper.js`)،
  ولی **selectorهای دقیق صفحه گلستان دانشگاه خودت رو باید خودت پر کنی** — چون هر دانشگاه یه نسخه‌ی
  کمی متفاوت از گلستان داره و من به سایت واقعی دانشگاه شما دسترسی ندارم.
- هر چند دقیقه (قابل تنظیم) خودکار چک می‌کنه و اگه نمره‌ای عوض شده بود، از طریق یک ربات تلگرام
  به کاربر پیام می‌ده.

## راه‌اندازی

```bash
npm install
cp .env.example .env
```

سپس در فایل `.env`:
1. `GOLESTAN_URL` رو به آدرس گلستان دانشگاه خودت تغییر بده.
2. یک کلید رمزنگاری بساز و در `ENCRYPTION_KEY` بذار:
   ```bash
   node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
   ```
3. `CHROME_EXECUTABLE_PATH` رو به مسیر Chrome نصب‌شده روی سیستمت بده (چون از `puppeteer-core`
   استفاده شده تا دانلود سنگین کروم لازم نباشه).
4. یک ربات تلگرام با `@BotFather` بساز و توکنش رو در `TELEGRAM_BOT_TOKEN` بذار.

اجرا:
```bash
npm start
```

## قدم باقی‌مانده: پیدا کردن selectorهای واقعی

1. سایت گلستان دانشگاهت رو باز کن، `F12` بزن (Developer Tools).
2. روی فیلد «شماره دانشجویی» راست‌کلیک کن → Inspect → `id` یا `name` اون input رو کپی کن.
3. همین کار رو برای فیلد گذرواژه، دکمه ورود، و باکس «کد گزارش سریع» انجام بده.
4. مقادیر `USERNAME_SELECTOR`، `PASSWORD_SELECTOR`، `SUBMIT_SELECTOR`، و `QUICK_REPORT_INPUT`
   رو در `src/services/golestanScraper.js` جایگزین کن.
5. توی همون فایل، بخش استخراج جدول نمرات (کامنت‌شده در `fetchGrades`) رو با ساختار واقعی
   جدول گزارش ۷۹ (کارنامه ترمی) که توی دواتولز می‌بینی هماهنگ کن.

## دیپلوی رایگان روی Render (بدون هزینه، برای خودت و دوستات)

1. یه ریپازیتوری گیت‌هاب بساز (رایگان) و کل پوشه `adib-server` رو توش push کن.
2. وارد `render.com` شو و با گیت‌هاب ثبت‌نام کن (پلن Free نیاز به کارت نداره).
3. **New → Web Service** → ریپازیتوری رو انتخاب کن.
4. Render فایل `render.yaml` رو خودش تشخیص می‌ده و Environment رو روی Docker می‌ذاره
   (چون `Dockerfile` توی پروژه هست و کرومیوم رو خودش نصب می‌کنه).
5. پلن رو روی **Free** بذار.
6. این مقادیر رو در بخش Environment Variables پر کن:
   - `GOLESTAN_URL` → آدرس گلستان دانشگاهت
   - `ENCRYPTION_KEY` → با `node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"` بسازش
   - `TELEGRAM_BOT_TOKEN` → توکن ربات تلگرامی که با BotFather ساختی
7. Deploy کن. بعد چند دقیقه یه آدرس مثل `https://adib-server.onrender.com` می‌گیری.

### جلوگیری از خوابیدن سرویس (پلن Free بعد از ۱۵ دقیقه بی‌کاری می‌خوابه)
برو به `cron-job.org` (رایگان، بدون نیاز به کارت)، یه حساب بساز، و یه cron job تنظیم کن که هر
۱۰ دقیقه یک‌بار به آدرس `https://adib-server.onrender.com/api/health` درخواست بزنه. این کار
سرویس رو بیدار نگه می‌داره تا کرون‌جاب داخلی چک نمرات هم بدون وقفه کار کنه.

### دوستات چطور بهش وصل بشن
هر کس با شماره دانشجویی و رمز خودش (فقط رمزنگاری‌شده روی همین سرور مشترک ذخیره می‌شه، نه جای دیگه)
به `POST https://adib-server.onrender.com/api/auth/login` وصل می‌شه. چون دیتابیس بر اساس
studentId جداست، همه می‌تونن از یه سرور مشترک رایگان استفاده کنن بدون اینکه نمرات هم رو ببینن.

## اتصال به فرانت‌اند سایت ادیب

توی `index.html` سایت، دکمه‌ی «ورود به گلستان» فعلاً غیرفعاله. وقتی این بک‌اند رو روی یه سرور
(مثلا Railway، Render، یا یه VPS) بالا آوردی، اون دکمه رو به یه فرم واقعی تبدیل کن که به
`POST /api/auth/login` این سرور درخواست بفرسته.

## هشدار امنیتی و مسئولیتی

- این پروژه گذرواژه دانشجوها رو ذخیره می‌کنه. حتما HTTPS استفاده کن، `.env` رو هیچ‌وقت commit نکن،
  و دسترسی به سرور رو محدود نگه دار.
- قبل از استفاده گسترده، بررسی کن که اتوماسیون ورود به گلستان با قوانین و شرایط استفاده دانشگاهت
  در تضاد نباشه.
- درخواست‌های زیاد و پشت‌سرهم به گلستان ممکنه باعث بلاک شدن IP یا حساب بشه؛ `CHECK_INTERVAL_MINUTES`
  رو معقول نگه دار (مثلا ۳۰ دقیقه یا بیشتر).
